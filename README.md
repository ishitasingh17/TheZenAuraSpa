# 🌿 The Zen Aura Spa Digital Consultation System

## Overview

The Zen Aura Spa Consultation App is a web application built with React, TypeScript, and Vite to help clients discover spa treatments that best match their wellness needs through an interactive consultation.

The goal is to provide an engaging consultation experience before booking a treatment.

---

## Features

- Welcome screen
- Service selection based on customer goals
- Personalized treatment recommendations

---

## Technologies Used

- React
- Vite
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ishitasingh17/TheZenAuraSpa.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
